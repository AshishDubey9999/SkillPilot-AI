# SkillPilot AI

AI-powered placement and skill progress tracker built with Next.js, Express, MongoDB and Gemini.

## Local development
```bash
npm install
npm run dev
```
In a second terminal:
```bash
npm run server:dev
```

See `BACKEND_SETUP.md` for local environment configuration and `DEPLOYMENT.md` for production deployment.
